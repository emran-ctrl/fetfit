# fetfit IDP

Easy-to-digest software, kitchen to table. The fetfit internal developer
platform is built on Backstage and gives every team one place to find, launch,
and operate their services.

## What you'll find here

- **Catalog** — every service, system, API and resource, with owners attached.
- **Create** — golden-path templates that spin up a new service, wire it into
  the catalog, and set up its docs automatically.
- **Docs** — TechDocs pages generated from each service's own repository.
- **Search** — one box to find software, teams, APIs and documentation.

## How things connect

Services live in their own repositories. Each one carries a
`catalog-info.yaml` describing itself, so the catalog grows as teams build —
no central master list to maintain.
